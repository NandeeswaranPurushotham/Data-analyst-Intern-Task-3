SQL Data Analysis Project using MySQL
Skills Demonstrated

1. Data Retrieval and Filtering

* Used `SELECT` statements to retrieve required data from tables.
* Applied `WHERE` clauses to filter records based on specific conditions.
* Utilized `ORDER BY` to sort data in ascending and descending order.
* Implemented `GROUP BY` to organize data into meaningful groups for analysis.

2. Joins

* Used `INNER JOIN` to combine matching records from multiple tables.
* Applied `LEFT JOIN` to retrieve all records from the left table along with matching records from the right table.
* Utilized `RIGHT JOIN` to retrieve all records from the right table along with matching records from the left table.

3. Subqueries

* Created subqueries to perform complex data retrieval operations.
* Used nested queries for filtering, aggregation, and comparison tasks.

 4. Aggregate Functions

5. Views

* Created SQL Views to simplify complex queries.
* Used views for reusable and efficient data analysis.

6. Query Optimization

* Created indexes on frequently searched columns.
* Improved query performance and reduced execution time.
* Applied database optimization techniques for efficient data retrieval.
